# dsh-git-plus

DeepSeek Harness Web 插件：在当前会话中查看 Git 变更、预览 diff，并通过标题栏的仓库树管理当前目录及子目录中的 Git 仓库和本地分支。提交、推送由 `dsh-quick-prompts` 的默认快捷指令启动原生后台子 Agent，沿用快捷任务 card 与审批机制。

仓库树保留中间目录层级，支持独立子仓库、已初始化的 submodule 和 linked worktree。布局紧凑：目录行高约 25px、缩进收窄，当前分支不做常驻高亮，只在每行右侧保留一个分支下拉入口。点击分支名打开该仓库的分支选择器，可搜索本地分支和已获取的远程跟踪分支；选择本地分支直接切换，选择远程分支会创建同名本地跟踪分支并设置上游（若同名本地分支已存在则明确报错，不会静默切换到无关分支）。切换仍会重新校验会话目录归属、目标实际路径和分支；只作用于选中的仓库，不自动切换其他仓库、暂存、强制覆盖、fetch/push 或更新子模块。Git 拒绝切换时保留工作区并展示错误。

工具栏状态由一次 `git status` 调用立即给出（分支与文件列表）；`+N -N` 行数统计经独立接口懒加载，其中未跟踪文件逐个 `diff --no-index` 计数，最多统计 200 个文件且预算 2.5 秒，超出的文件不计入（角标为部分统计），避免大型未跟踪目录拖垮慢速机器。确认非 Git 的目录不显示工具栏；后台轮询不会取消仍在途中的前一次响应。

自动检测最多深入 8 层、扫描 2,000 个目录、返回 100 个仓库，并设置约 3 秒扫描预算；跳过符号链接目录和常见依赖/缓存目录。已发现结果缓存 15 秒，可点「重新检测」刷新。达到限制或目录读取失败时，菜单明确显示结果可能不完整，可打开更具体的项目目录管理剩余仓库。未初始化的子模块不自动 clone/init；仓库树只管理本地已有的工作树。

## 安装

```sh
dsh plugin --profile web add ./plugins/dsh-git-plus
```

重启 `dsh web`。

## 配置

在 profile 的 `cordis.patch.yml` 覆盖：

```yaml
- id: dsh-git-plus
  config:
    gitExecutable: /path/to/git  # 空则使用 Host PATH 中的 git
    gitExecPath: ''              # 便携 Git 可填写 libexec/git-core 目录
    provider: ''                 # 空则优先使用 DSH 默认模型的 provider ID
    model: ''                    # 空则优先使用匹配 provider 的默认模型
    prompt: '用中文写一条 Conventional Commits 提交说明，只输出正文。'
```

桌面端同样使用上述配置，覆盖文件为 `~/.dsh/profiles/desktop/cordis.patch.yml`，修改后重启应用。若 macOS 系统 Git 被 Xcode 协议阻止，可指定已安装的其他 Git；插件会显示实际执行错误。配置只影响本插件的 Host Git 调用，不改变终端或 Agent 使用的 Git。

`git status` / `git diff` 由 Host 执行，cwd 必须属于已存在会话的工作目录（包括从持久化恢复的会话）。子仓库使用相对于该目录的路径；服务端在每次列分支和切换时重新校验实际路径，拒绝目录越界、符号链接穿越及把普通子目录冒充独立仓库。分支切换由 Host 执行；提交和推送走快捷任务的原生后台子 Agent。

多仓库功能通过临时真实 Git 仓库进行自动化回归；尚未在当前桌面 App 重启后验收。

已在 DSH **0.2.0-rc.2** 验证变更、中文文件名、未跟踪文件对比和生成提交说明。支持尚未首次提交的新仓库。模型配置为空时跟随 DSH 默认配置；没有默认配置时按 provider ID 查找可用模型。模型错误或不完整结果会显示错误，不填入空说明。本轮未实际提交或推送项目。
