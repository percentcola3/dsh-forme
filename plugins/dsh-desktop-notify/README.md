# dsh-desktop-notify

DSH 的独立桌面提醒插件。服务端监听全部普通会话的实时事件，macOS 原生非激活悬浮窗在应用前台、后台、最小化或其他桌面空间时均可显示，不依赖当前选中的任务，也不会抢走键盘焦点。

## 使用

安装整套 `dsh-forme`，或单独添加：

```sh
dsh plugin --profile desktop add 'git+ssh://git@github.com/percentcola3/dsh-forme.git#path:plugins/dsh-desktop-notify'
```

重启 DSH 后，点击左下角账号菜单中的「桌面提醒」，或进入设置的「通用」配置。选择屏幕左侧、右侧、顶部或灵动岛样式，支持主显示器/鼠标所在显示器、3–30 秒自动收起时长（新安装默认 5 秒，保留已有配置）、完成提醒、审批/问题提醒及提示音。点击「保存设置」立即生效，测试按钮也会保存当前设置。

- 正常完成一轮任务时提醒；取消、中断、拒绝和空转不显示为完成。异常单独提示。
- 完成、异常、工具审批与 `ask_user_question` 问题提醒都会按配置时长自动消失；请求提前处理后立即收起。提醒消失不会回答问题、批准操作或取消任务，未处理的请求仍在会话内等待。
- 同时到达的提醒排队，优先显示需要选择的任务；子代理内部事件不单独刷屏。
- 点击星球唤起已有的 DeepSeek Harness 窗口，由插件打开对应会话。提醒本身不会代答问题或批准操作。
- 提醒使用 48×48pt 的透明画布，仅显示一颗星球，不再使用长胶囊、尾流或文字。完成时是淡蓝色自转地球；审批、问题或异常时整颗切换为黑红月球。任务名与状态保留给辅助阅读及悬停提示。四种位置均避开菜单栏与刘海，无需系统通知授权。
- 地球使用本地 NASA 地表纹理、独立云层与球面大气散射；月球使用本地 NASA 月面与高程纹理计算法线细节，搭配暗色表面与红色侧光。SceneKit 以 30fps 渲染，进出场轻微滑动并淡入淡出。遵循系统减少动态效果设置，隐藏后释放渲染视图。悬停和新提醒排队都不会无限延长当前提醒。

## 平台与生命周期

自定义桌面位置当前支持 **macOS 12 及以上**。首次使用需要本机 Xcode Command Line Tools 的 `swiftc`，原生辅助程序从随包 Swift 源码编译并缓存在 `~/.dsh/cache/desktop-notify/`。源码更新后完整重开 DSH 即可使用新的缓存版本。不下载可执行文件、不修改 DSH 安装包，也不创建后台登录项。DSH/插件退出后，辅助程序随输入管道关闭退出。其他系统会在配置面板明确显示当前不支持原生定位，不伪装成可跨应用显示的网页提示。

设置保存在 `~/.dsh/desktop-notify.json`；最近提醒仅存进程内存，不额外记录聊天历史。应用退出或机器休眠时不会执行任务；锁屏、屏幕保护程序和 macOS 对全屏窗口的管理仍由系统控制。

## 开发验证

```sh
pnpm typecheck
pnpm test
pnpm build
pnpm exec tsdown --config preview/tsdown.config.ts
node preview/server.mjs
```

访问 `http://127.0.0.1:4180/`。预览使用隔离设置和模拟会话，调用同一生产事件监听器与原生辅助程序，可测试完成、等待选择、回答和取消，不向真实任务发送消息。
