# dsh-quick-prompts

输入框顶部的快捷任务栏。点击 **+** 新增名称和任务内容，点击执行，点击铅笔或右键编辑。按钮最多展示五个字，悬停查看全名。

所有快捷指令统一交给 **DSH 原生后台子 Agent**：沿用主 Agent 的模型、工作目录、预设及权限，使用 fresh context，不复制主对话历史。自然语言和命令都由 AI 处理，不再区分三种模式。旧配置中的名称和任务原文保持不变，旧 `mode` 和模型选择不再生效。

启动请求只等待任务提交，不等待模型执行。右侧非模态浮层展示启动、执行、等待处理、完成、停止和失败，附带耗时、步骤、最近六次工具调用及文本结果。任务结果由插件接收，不会自动向主 Agent 注入消息或切换主对话。点击「完整记录」才打开原生子任务会话；需要处理问题或审批时也从这里进入。权限限制和执行失败会如实显示，不绕过 DSH 的规则。

可同时运行不同快捷任务；同一主会话的同一快捷任务正在执行时不会重复启动。停止只影响对应子任务，等待原生结果确认后显示已停止。收起面板、切换会话、刷新页面都不会重新启动任务。浮层不占据底部输入区，可随时收起。

配置保存在 `~/.dsh/quick-prompts.json`，串行原子写入。运行列表在 Host 进程内保存最近 100 条，浮层显示最新 20 条并优先展示执行中的任务；文本结果最多保留 24,000 字符，完整内容可在原生记录中查看。**重启 DSH 后浮层列表不保留**，已落盘的子任务仍可通过 DSH 原生子智能体列表查看。卸载插件时仅释放本插件启动的子任务。

依赖官方 `agents`、`subagents` 及 `spawn` provider；请启用 DSH 内置子智能体。已在 macOS 官方桌面端 **0.2.1-rc.2** 验证三类旧快捷指令全部以原生子 Agent 运行，并行执行、返回文本/命令结果、停止、主输入编辑及完整记录跳转。主会话轮次保持不变。Host 代码更新后在插件管理器停用再启用此组件；若宿主缓存旧模块，完整重开 App。

验证（Node 22+）：

```sh
pnpm run build
pnpm exec tsc --noEmit
node --experimental-strip-types --test tests/*.test.mjs
```
