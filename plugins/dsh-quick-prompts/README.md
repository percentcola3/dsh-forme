# dsh-quick-prompts

输入框顶部的快捷任务栏。点击 **+** 新增名称和任务内容，点击执行，点击铅笔或右键编辑。按钮最多展示五个字，悬停查看全名。

所有快捷指令统一交给 **DSH 原生后台子 Agent**：沿用主 Agent 的模型、预设及权限，并显式使用当前项目目录，使用 fresh context，不复制主对话历史。自然语言和命令都由 AI 处理，不再区分三种模式。旧配置中的名称和任务原文保持不变，旧 `mode` 和模型选择不再生效。

右侧只展示**进行中的任务卡片**，保留执行、等待处理和正在停止的任务；完成、失败或停止后立即移除，不展示历史任务。卡片外没有容器边框、背景、标题或记录计数，卡片里显示实时输出，顶部仅保留任务名、「中断」和关闭按钮。中断只作用于当前子任务；关闭会停止并移除该任务，其他卡片继续运行。不显示耗时、摘要或历史。输出前仅显示轻量占位动画。

AI 正文接入 DSH 的 `agent/assistant-stream` 事件，在生成过程中更新；工具返回的文本也会加入当前任务输出。已提交的正文会与流式文本合并，避免重复显示。每 400ms 同步到界面，单卡保留最近 24,000 字符。输出自动跟随末尾；向上滚动阅读时暂停跟随，滚回底部后恢复。

卡片嵌入对话区右侧的 250–320px 布局列，与消息和输入框共同排版，任务列表独立滚动。没有进行中任务时，右侧不占空间，消息与输入框自动恢复原宽度。对话区域不足 820px 时，卡片改为下方布局。输入框上方只在存在进行中任务时显示「后台任务 N」开关，收起卡片不影响执行。切换到插件等页面时不展示卡片。

子任务结果由插件接收，不会自动向主 Agent 注入消息或切换主对话。每个项目可并行执行多个任务，同一条指令也可再次启动为独立实例。短时间重复提交同一请求编号会去重。需要查看完整记录或处理问题/审批时，从 DSH 顶部原生子智能体列表进入。启动、执行或同步错误显示在输入框上方；权限和审批继续由 DSH 控制。

配置保存在 `~/.dsh/quick-prompts.projects.json`，以会话项目目录的真实路径分组，串行原子写入。各项目分别保存最多 100 条指令；任务查询、中断和关闭均校验项目归属。切换项目时立即清空旧视图，丢弃迟到的旧项目响应。旧版 `~/.dsh/quick-prompts.json` 保留为备份；点击「导入旧指令」可将其一次性归入当前项目，不会自动复制到其他项目。Host 进程内最多跟踪 100 条任务以支持去重和生命周期清理，已结束任务不会显示为卡片。刷新页面和切换会话不会重新启动任务。重启 DSH 后进程内跟踪记录不保留，已落盘的子任务仍可通过 DSH 原生子智能体列表查看。卸载插件时仅释放本插件启动的子任务。

依赖官方 `agents`、`subagents` 及 `spawn` provider；请启用 DSH 内置子智能体。已在 macOS 官方桌面端 **0.2.1-rc.2** 验证项目隔离、旧指令导入、同指令双任务并行、独立关闭/中断，以及正文生成时的实时卡片更新。验收使用只读命令，主会话轮次保持不变。Host 代码更新后在插件管理器停用再启用此组件；若宿主缓存旧模块，完整重开 App。

pnpm exec tsc --noEmit
node --experimental-strip-types --test tests/*.test.mjs
