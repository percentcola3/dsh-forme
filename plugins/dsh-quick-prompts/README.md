# dsh-quick-prompts

输入框顶部的快捷任务栏。点击 **+** 新增名称和任务内容，点击执行，点击铅笔或右键编辑。按钮最多展示五个字，悬停查看全名。

所有快捷指令统一交给 **DSH 原生后台子 Agent**：沿用主 Agent 的模型、工作目录、预设及权限，使用 fresh context，不复制主对话历史。自然语言和命令都由 AI 处理，不再区分三种模式。旧配置中的名称和任务原文保持不变，旧 `mode` 和模型选择不再生效。

右侧只展示**进行中的任务卡片**，保留执行、等待处理和正在停止的任务；完成、失败或停止后立即移除，不展示历史任务。卡片外没有容器边框、背景、标题或记录计数，卡片里只显示实时输出，不显示任务信息、耗时、摘要或详情按钮。输出前仅显示轻量占位动画。

AI 正文接入 DSH 的 `agent/assistant-stream` 事件，在生成过程中更新；工具返回的文本也会加入当前任务输出。已提交的正文会与流式文本合并，避免重复显示。每 400ms 同步到界面，单卡保留最近 24,000 字符。输出自动跟随末尾；向上滚动阅读时暂停跟随，滚回底部后恢复。

卡片嵌入对话区右侧的 250–320px 布局列，与消息和输入框共同排版，任务列表独立滚动。没有进行中任务时，右侧不占空间，消息与输入框自动恢复原宽度。对话区域不足 820px 时，卡片改为下方布局。输入框上方只在存在进行中任务时显示「后台任务 N」开关，收起卡片不影响执行。切换到插件等页面时不展示卡片。

子任务结果由插件接收，不会自动向主 Agent 注入消息或切换主对话。同一主会话的同一快捷任务正在执行时不会重复启动，不同任务可并行。需要查看完整记录、停止任务或处理问题/审批时，从 DSH 顶部原生子智能体列表进入。启动、执行或同步错误显示在输入框上方；权限和审批继续由 DSH 控制。

配置保存在 `~/.dsh/quick-prompts.json`，串行原子写入。Host 进程内最多跟踪 100 条任务以支持去重和生命周期清理，已结束任务不会显示为卡片。刷新页面和切换会话不会重新启动任务。重启 DSH 后进程内跟踪记录不保留，已落盘的子任务仍可通过 DSH 原生子智能体列表查看。卸载插件时仅释放本插件启动的子任务。

依赖官方 `agents`、`subagents` 及 `spawn` provider；请启用 DSH 内置子智能体。已在 macOS 官方桌面端 **0.2.1-rc.2** 验证旧快捷指令的后台启动、并行执行、命令结果、停止，以及正文生成时的实时卡片更新。主会话轮次保持不变。Host 代码更新后在插件管理器停用再启用此组件；若宿主缓存旧模块，完整重开 App。

验证（Node 22+）：

```sh
pnpm run build
pnpm exec tsc --noEmit
node --experimental-strip-types --test tests/*.test.mjs
```
