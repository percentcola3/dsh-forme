# dsh-quick-prompts

输入框顶部的快捷任务栏。点击 + 新增，右键编辑或删除；按钮最多展示 5 个字。

- 当前对话：发送完整提示词，使用当前模型和上下文，保留输入草稿。
- 独立 Agent：官方 sessions.create 新建相同工作目录的会话，不复制聊天历史。可选择官方目录中的模型和对应思考强度；不影响主会话。系统默认使用新会话的默认模型。结果、权限审批通过官方独立会话查看，任务栏可停止；最近结果链接保存在本机。
- 终端命令：在当前会话目录通过 zsh 执行保存的命令，不调用模型。每个目录同时执行一个快捷命令；输出面板显示日志、退出码并可停止。适合前台命令，不是交互式终端。输出上限 200,000 字符，退出服务清理进程组。

历史配置缺少 mode 时仍按当前对话执行。配置存放在 ~/.dsh/quick-prompts.json，模型配置只对独立 Agent 生效。失败不自动重试。任务栏预留 76px，错误再增加 28px。

插件独立安装，无需启用项目启动插件。Host 变更后完整重开 App。

已在官方桌面端 **0.2.0-rc.2** 实测三种模式。会话导航使用 `uiWorkspace`；独立 Agent 显式保留会话并等待就绪后才配置模型、发送任务，结果观察结束时释放引用。

验证（Node 22）：pnpm run build、pnpm exec tsc --noEmit、node --experimental-strip-types --test tests/*.test.mjs。
