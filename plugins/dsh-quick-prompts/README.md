# dsh-quick-prompts

输入框顶部的快捷任务栏。点击 **+** 新增名称和任务内容，点击执行，点击铅笔或右键编辑。按钮最多展示五个字，悬停查看全名。

普通「新建任务」或切回项目时，优先打开该项目已有未发送内容的空会话，复用 DSH 官方草稿存储及引用数据，不再把带草稿的空会话隐藏后另建一个空白页。项目之间相互隔离；发送或手动清空后恢复普通新建行为；显式清空、预填内容和预设切换仍遵守官方导航逻辑。

Git 工作区会默认加入「提交」和「推送」两条普通快捷任务（包含嵌套目录和 Git worktree）。可像其他任务一样编辑、删除和并行运行；默认任务只初始化一次，删除后不会重新添加，编辑内容在重启后保留。目录不再是 Git 工作区时隐藏这些默认任务并拒绝启动，普通自定义任务不受影响；约每 15 秒重新检查，初始化 Git 后无需切换会话。提交任务只处理明确相关的改动且不推送；推送任务只正常推送已有提交，不创建提交或强制推送。目标或改动范围不明确时交由独立会话中的 AI 询问，权限与审批沿用官方流程。

每次点击快捷指令会创建一个 **DSH 普通独立会话**，用任务原文作为第一条用户消息，当前项目目录作为工作目录。主对话继续运行，不复制主对话历史，也不通过子 Agent 结果通知唤醒主对话。自然语言与命令均由 AI 在该会话内处理。新会话沿用所选预设，权限和审批遵守 DSH 普通会话的原生规则。

编辑时可选择执行模型，按提供方分组。「跟随当前会话模型」在启动时读取当前会话的模型；固定模型随指令保存。模型配置只作用于新快捷对话，不改变主对话或全局默认模型。模型失效时明确报错，不静默改用其他模型。

右侧卡片是轻量对话界面：显示用户消息与 AI 公开正文，底部有简单输入框。Enter 发送，Shift+Enter 换行；中文输入法确认不会误发送。AI 回复时可先编写下一条消息，当前轮结束后发送。后续消息进入**同一会话**，保留上下文；请求携带稳定编号，网络重试不重复执行。失败时保留输入并显示错误。

完成或停止后卡片保留，方便继续追问。停止仅中断当前对话，关闭会停止执行、清空排队输入并移除卡片，释放插件专用的模型监听；完整会话记录保存在 DSH 中，不删除历史。其他卡片和主对话不受影响。点击卡片顶部 ↗ 可进入完整对话，处理工具审批或结构化问题。轻量界面不嵌入复杂工具交互，也不展示原始工具输出或内部推理。

AI 正文接入原生 `agent/assistant-stream` 事件，只累计 `text-delta`，提交的 `assistant/message` 校正流式正文，避免重复。执行中约每 600ms 同步，空闲时 3 秒，窗口隐藏时暂停。未变化的数据不重新渲染；各卡片只更新自己的变化。单次回复保留最近 24,000 字符，卡片投影最多保留 48 条消息/约 96,000 字符，完整历史以 DSH 会话为准。向上滚动阅读时暂停自动跟随，返回底部后恢复。

卡片嵌入右侧 280–360px 布局列，与主消息和输入框共同排版。没有卡片时不占空间；对话区域不足 820px 时改为下方布局。「快捷对话 N」按钮可收起或重新显示已完成的卡片，收起不影响执行。切换到插件等页面时不显示卡片。

每个项目分别维护自己的卡片列表、终端入口和展开/收起状态。同项目切换会话后恢复该项目的卡片，跨项目切换时立即隐藏旧项目卡片，目录解析未完成前不显示旧卡片。终端卡片绑定创建它的原生会话，切换项目或收起面板不关闭 PTY；同项目的其他会话显示「返回原终端」入口，避免原生侧栏的会话限制导致空白终端或重建 shell。回到原会话时恢复原终端，显式关闭卡片才结束该终端。

配置保存在 `~/.dsh/quick-prompts.projects.json`，按项目真实目录隔离，串行原子写入。各项目最多 100 条自定义指令，另有 2 条 Git 默认任务。查询、续聊、停止和关闭均验证项目归属；切换项目时立即清空旧视图并丢弃旧项目的迟到响应。旧全局指令可显式导入一次。Host 进程内最多跟踪 100 个会话，达到上限时回收最早的已结束记录。重启 DSH 后卡片跟踪不保留，已创建的普通会话历史仍由 DSH 保存，可从会话列表查看；刷新页面和切换会话不重新启动任务。卸载插件时仅中断其拥有的快捷对话，不删除会话历史。

依赖官方 `sessionController`、`agents` 以及普通会话 API，无需 spawn provider。适配当前 macOS 官方桌面端 **0.2.1-rc.2** 的公开会话与事件接口。更新后在插件管理器停用再启用；若宿主缓存旧模块，完整重开 App。轻量对话的交互通过本地模拟会话预览验证；会话创建、同会话续聊、模型隔离、停止及请求去重均有适配器回归测试，未在当前工作会话中额外调用付费模型执行验收。

主会话 AI 任务支持重启续接：插件只记录启用后观察到正在执行的普通主会话（包括加载插件时已在运行的任务），记录保存在 `~/.dsh/quick-prompts-recovery.json`。下次启动时，只有原执行轮次确实因退出或崩溃中断、没有新消息/新轮次、没有正在运行的 Agent 或待处理输入且会话未归档时，才通过官方 `sessionController` 恢复原会话并提交一次带插件来源标记的续接通知。原命令和工具调用不会被机械重放；工具结果不确定时，由官方日志修复和后续 Agent 核对外部状态。主动停止、已完成、错误/阻塞和子 Agent 任务不自动恢复，也不扫描历史旧任务。

续接提交前先原子写入一次性标记；若在写标记与提交之间退出，或恢复失败，原对话会提示检查记录后手动发送「继续」，不会自动反复提交。恢复启动一个新的原生续接轮次；官方目标（goal）的激活状态不被擅自更改，重启后取消激活的目标需用户显式恢复，才能继续自动目标轮次。已覆盖实际写盘后多次重建恢复协调器的回归测试；未通过退出当前桌面 App 做端到端验收。

主会话标题会在一轮正常结束后，利用当前会话的模型，根据最近的用户提问和公开回复生成简短主题，帮助从侧栏重新接上上下文。首轮命名继续沿用官方机制；后续主题变化时更新自动标题。手动命名保持不变；不使用工具输出、内部推理或自动恢复通知作为标题素材。更新写入官方持久化标题事件，不向主对话发送消息，也不另起任务。生成期间若有新输入、新轮次、手动改名或会话关闭，会取消或丢弃过期结果；失败时保留旧标题。功能启用后随新完成的对话生效，不批量重命名历史会话，并会增加一次轻量模型调用。
