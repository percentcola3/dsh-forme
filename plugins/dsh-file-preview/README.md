# dsh-file-preview

点击顶部「文件」分段标签，切换到 **文件会话 Tab**：左边是完整的官方 Files 工作区树，右边是官方文档预览。未选文件时右侧显示提示，点击文件会替换右侧预览。每次进入文件 Tab，左侧目录通过官方分栏接口收窄到约 22% 宽度（DockKit 最小允许 20%），把空间留给预览；进入后手动拖动分隔条会被保留，直到下次进入。支持目录展开、行悬停和当前文件选中效果。

文件区域仅占据会话 Tab 内容，保留顶部、左侧会话列表和底部输入栏；切回对话或 Changes 后恢复侧栏显示状态。不进入全屏，不自研文件树、Markdown 或代码渲染器。

**侧栏清理**：文件 Tab 打开的文件树借用官方侧栏面板嵌入。离开文件 Tab 时，插件会关闭自己打开的文件标签（用户自己打开的则不会动）；官方 settle 规则随后合并空面板，展开侧栏时回到「开始」页，不会再留一份重复的文件树。

**头部工具**：会话标签行在路径后依次提供「复制路径」（整块路径即点击热区，点击复制并短暂显示 ✓）和「终端」（`>_`，一键打开 DSH 官方终端面板，走与系统快捷键相同的代码路径）。项目是 Git 工作区时路径前显示 Git 图标，非 Git 不显示图标；检测经服务端端点完成并缓存。

官方组件仍由原始右侧栏挂载。插件使用会话区域的实时尺寸限定其显示边界，通过官方 split/openResourceIn 分栏及打开文件。已适配并在 Harness **0.2.0-rc.2** 验证；依赖官方服务和 DOM 标记，后续升级仍需要复核。

```sh
dsh plugin --profile web add ./plugins/dsh-file-preview
```

首次安装需要重启服务；仅修改客户端后构建并在 App 内按 ⌘R，无需重打 App。

验证（Node 22）：

```sh
pnpm run build
pnpm test
pnpm exec tsc --noEmit
```

在右侧文件预览中右键：有选区显示「将代码插入 Chat」，无选区显示「将文件插入 Chat」。使用官方文件引用 chip，文件名优先、长路径自动省略，悬停可看完整路径。代码选区可定位时在引用后附带行号文本，引用本身保持有效路径，点击可打开原文件；两者都只传路径与位置，不贴源码。保留原有草稿和引用，不自动发送。此前已插入的纯文本路径不自动改写。

顶部视图顺序为「对话 / 文件 / Changes / 轨迹」。右侧工作区路径为只读 chip，完整路径可悬停查看。
